Séquence :
1. commit/push puis pull serveur ;
2. bash scripts/deploy-e045-notebook.sh all
3. bash scripts/run-e045-foundation.sh
4. attendre ===== E045 TERMINÉ =====

En cas de crash :

- relancer bash scripts/run-e045-foundation.sh ;
- status : bash scripts/run-e045-foundation.sh status ;
- logs : bash scripts/run-e045-foundation.sh logs.

relancer aveuglément.
