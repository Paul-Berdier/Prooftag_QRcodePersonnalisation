4. Ce que les tests locaux ne peuvent pas prouver
--------------------------------------------------
Aucun environnement local ne reproduit la RTX 4000 SFF Ada, le runtime NVIDIA K3s et les caches
modèles de pcIA. Il serait donc incorrect de promettre qu'un nouveau chemin GPU est infaillible
sans l'exécuter réellement sur pcIA.

Pour fermer précisément ce risque, E048 exécute après la coupure vLLM un CANARY GPU réel d'une
itération utilisant le même chemin que le Job long : latent E047 -> pipeline DiffQRCoder ->
SR-MPGD -> LPIPS -> QR-Verify. Le Job long n'est lancé que si `GPU_CANARY_PASS.json` est écrit.
Si le canary échoue, le superviseur déclenche la récupération de vLLM et n'entame pas la campagne.
